# DS101 - Segmentación de clientes (Mall Customers)

TP de Data Sciences 101 (UCEMA MBA): agrupar los 200 clientes del dataset Mall Customers con K-means para inferir conductas de compra y proponer acciones de marketing por segmento.

## Contenido

| Carpeta / archivo | Qué es |
|---|---|
| `fuentes/Mall_Customers.csv` | Dataset de origen |
| `scripts/01_analisis_segmentacion.py` | Script reproducible (semilla 42) |
| `outputs/Respuestas_concretas_TP_Segmentacion.md` | Informe breve con las respuestas a las consignas |
| `outputs/Analisis detallado de Segmentacion de Clientes Mall.md` | Análisis completo |
| `outputs/Anexo_Prompts.md` | Guion de prompts para reproducir el análisis con IA |
| `outputs/tablas/`, `outputs/figuras/` | Resultados numéricos y gráficos |

## Resultado principal

5 segmentos con K-means sobre ingreso anual y Spending Score estandarizados (silueta 0.555). La edad se usa para describir los segmentos, no para agruparlos.
